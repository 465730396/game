# 陕北捉老麻

一款 2～4 人的地方性扑克牌游戏。本仓库是**微信小程序工程**，同时归档了一份可在浏览器直接运行的 **H5 试玩版**，两者共用同一套规则引擎与 AI。

## 目录结构

```
game/
├── app.js / app.json / app.wxss / sitemap.json   # 小程序入口与全局配置
├── pages/                       # 小程序页面（每页 js / wxml / wxss / json）
│   ├── index/                   # 首页：模式、人数、难度、续局入口
│   ├── game/                    # 牌桌：选牌、出牌、提示、AI 调度、热座交接
│   ├── result/                  # 结算
│   ├── rules/                   # 玩法规则
│   ├── stats/                   # 本机战绩与排行榜
│   ├── settings/                # 音效、振动、大字模式、运行诊断
│   └── privacy/                 # 用户隐私保护指引（含"删除本机数据"）
├── utils/
│   ├── audio.js                 # InnerAudioContext 音频管理
│   ├── privacy.js               # 隐私协议 + 相册授权封装
│   └── fx.js                    # Canvas 2D 背景与庆祝特效
├── assets/audio/                # 程序合成的 mp3 音效与 BGM（无版权素材，共约 58KB）
├── bundle.js                    # 核心逻辑唯一真相源：规则引擎 / AI / 控制器 / 存储
├── h5/                          # H5 试玩版（index.html + app.js + fx.js + styles.css）
├── tools/                       # 测试与资源生成脚本
└── project.config.json          # 微信开发者工具项目配置
```

`bundle.js` 是纯逻辑模块，同时兼容浏览器 `<script>` 和小程序 `require`；小程序入口直接 `require('./bundle.js')`，不存在副本或同步步骤。

## 快速开始

### 微信小程序

1. AppID 已写入 `project.config.json`（当前 `wxafb07ccffcaffb77`）。换号时用 `node tools/set-appid.js <AppID>` 或直接改该字段。
2. 用微信开发者工具**导入本目录（game/ 根目录，不是子目录）**，编译即可预览。
3. 真机预览需在开发者工具中点击"预览"扫码。

`miniprogramRoot` 为 `./`，`packOptions.ignore` 已排除 `h5/`、`tools/`、`.git/`、`README.md`，它们不会被打进小程序包。发布相关编译项（ES6 转换、增强编译、压缩、`urlCheck`）已在 `project.config.json` 中按发布配置开启。

### H5 试玩版

直接用浏览器打开 `h5/index.html` 即可（无需构建、无外部依赖）。它引用上一级的 `bundle.js`，用于规则与交互的快速验收。

## 玩法规则

- **牌堆**：3 人局 51 张（去掉大小王、1 张 2，保留 4 张 A 与 3 张 2），每人 17 张；4 人局 52 张全牌，每人 13 张。2 人场暂未开放（引擎支持，理由见"已知事项"）。
- **首出**：首局由持红桃 3 者先出，首手必须包含红桃 3；一轮之内从第 2 局起，由上一局的**末位先出**（给落后方一次起手补偿，增强轮次内的翻盘感）。出牌方向为逆时针。
- **牌型**：单张、对子、三张、三带一、三带二、顺子（5 张起，最大到 K）、连对（3 组起）、飞机（2 组起）、四张炸弹、天炸（AAA；4 人局 AAAA 也识别为天炸）。
- **强制规则**：见单 K 必出 A · 见对 K 必出对 A · 见 A 必出 2 · 见 2 必出炸弹。手上确实无对应牌时可不出。
- **计分（娱乐积分）**：胜者得其他玩家剩余张数之和，其余玩家各扣自己的剩余张数，**每局所有玩家 delta 之和恒为 0**。炸弹采用倍率制：本局每出现 1 个炸弹，全桌输赢 ×2（天炸算 2 个），最高 ×4。5 局为一轮累计。逃跑只记次数不计分。
- **规则档**：首页可切换"经典 / 简化"。简化档关闭四条强制出牌规则，供新手过渡。剩余 3 张以内自动报牌；已落地的牌不可收回。

规则全部由 `bundle.js` 中的 `defaultRuleConfig(playerCount)` 描述，牌型识别 `detectType(cards, config)` 会读取配置，`allowA` / `allow2` / `maxRank` / 各牌型 `enabled` / `minGroups` / `bomb.tripleA` 等均真实生效。游戏内"规则"页列有若干待本地玩家确认的默认项，确认后改配置即可，无需改代码。

## 功能特性

- **人机 / 热座**两种模式；AI 提供简单、普通、困难三档，困难档基于对手手牌采样评估、不作弊，并会针对剩牌最少的玩家压制、在对手宽裕时留炸。
- **AI 人格**：人机对手使用固定名字与触发台词（出牌/炸弹/不要/报牌），避免"AI 1/2/3"式的做题感。
- **一轮多局**：5 局为一轮累计积分，牌桌顶部与结算页都显示"第 N/5 局"和累计榜，跨进程可恢复。从第 2 局起由上一局末位先出；轮次结束展示**逐局得分**，一眼看出分差是哪一局拉开的。
- **每日挑战**：以当天日期为 seed，每天固定同一副牌、单局定胜负；**成绩以当天首次完成为准**，之后重开只作练习不计分（否则同一副牌可无限试错刷成绩）。首页显示今日成绩。
- **强制规则教学**：每条强制规则第一次拦住玩家时弹窗讲清"凭什么我必须出"，之后退化为底部提示，不重复打扰。
- **完整对局出口**：牌桌可"重开"或"退出"。主动退出计入一次逃跑（只记次数、不计分）；用系统返回离开则保留对局，可从首页续玩。
- **断点续局**：快照包含模式/人数/难度/当前座位/轮次进度，首页直接显示进度（轮到谁、各家剩牌）；热座续局强制显示交接遮罩，防止偷看手牌。
- **对局引导**：首次进入有一次三句话引导（可在设置里重置）；首手自动选中红桃3；无牌可压时高亮"不出"并给出提示；"不出"被禁用时说明是哪条规则拦的；剩 1~3 张实时报牌，有人只剩一张时座位高亮预警。
- **牌桌信息**：手牌按点数排序；座位标记"上一手"；底部记牌器显示每个点数还没出现的张数。
- **手感反馈**：出牌区弹入动画；炸弹/天炸触发全屏震屏与重触感。
- **生命周期处理**：`onHide` 暂停 AI 定时器、音频与特效并保存快照，`onShow` 恢复。
- **结算**：按名次展示积分、剩余张数与炸弹数，标出炸弹倍率；热座使用"赢家"角标；"再来一局"沿用原模式/人数/难度并延续轮次。
- **战绩图分享**：结算页用 Canvas 2D 现画一张战绩卡，可保存到相册；分享自动带该图。
- **设置**：背景音乐、提示音、振动反馈、大字模式（全页面生效）、重看新手引导、运行诊断（复制本地异常记录）、用户隐私保护指引。
- **隐私与数据**：页内提供完整隐私指引正文（收集什么、用到哪些权限、不获取什么、如何删除），并支持一键清除本机对局数据（保留设置）。
- **本机战绩**：总局数/胜局/逃跑/累计积分、本地排行榜、最近对局（含时间与名次）；清空战绩不影响设置。

## 实现说明

- **核心与视图分离**：`bundle.js` 是无平台依赖的纯数据逻辑（内部包含规则引擎、AI、控制器、存储），视图层完全用 `setData` 驱动，不使用 DOM 或 `innerHTML`。
- **存储**：store 模块自动检测 `wx.getStorageSync`，小程序的走 wx 存储，浏览器回退到 `localStorage`。
- **音频**：小程序没有 WebAudio 程序合成 API，因此用 `tools/gen-audio.js` 以纯代码合成 WAV，再转 64kbps mp3 供 `InnerAudioContext` 播放（WAV 是未压缩 PCM，4 个文件 316KB；转 mp3 后共 58KB）。
- **隐私与相册**：`utils/privacy.js` 封装了「同意隐私协议 → 保存到相册」的正确顺序。必须在用户点击的同步链路里先调 `requirePrivacyAuthorize`，再画 canvas——反过来（画完再弹）手势上下文已丢失，弹窗拉不起来。失败按隐私未同意 / 相册被拒 / 系统级关闭 / 其他四类分流提示。
- **线上排错**：`app.js` 捕获 `onError` 与 `onUnhandledRejection`，保留最近 20 条异常到本地，设置页可复制；同时接入 `getUpdateManager`，发版后主动提示重启换包。
- **特效**：`utils/fx.js` 使用小程序 Canvas 2D（`SelectorQuery` 取节点 + `canvas.requestAnimationFrame`），实现星空、山峦、孔明灯、窑洞暖光与庆祝烟花。静态风景（三层山脉 + 4 个窑洞暖光）预渲染到离屏画布，每帧只 `drawImage` 一次；孔明灯光晕预渲染成贴图，用 `globalAlpha` 控透明度；帧率上限 30fps（背景是缓慢漂移，30 与 60 肉眼无差，耗电差一倍）。离屏画布不可用时自动退回逐帧绘制。
- **代码标记**：规则引擎中的历史修复带 `[FIX 2026-11-18]` 注释，上线补齐带 `[RELEASE 2026-11-18]`，本轮设计改进（倍率计分、轮次、规则档、手感、AI 人格、战绩图）带 `[DESIGN 2026-11-18]`，运行时事故与体验修复带 `[FIX 2026-11-19]`，便于追踪来源。
- **默认设置**：音效与振动默认开启、BGM 默认关闭。牌类游戏的出牌声与炸弹震感是核心手感，不能要求玩家先去设置页找开关；进页面自动放音乐则属于打扰。同时调用 `wx.setInnerAudioOption({ obeyMuteSwitch: false })`，避免 iOS 静音键把游戏变成哑剧。
